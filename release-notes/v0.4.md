Win-Preview v0.4 is a much smaller download: about 55 MB instead of 111 MB, with the same features.

## Download

**Win-Preview-v0.4-win-x64.zip** is for Windows 10 (1809+) and Windows 11, x64. Unzip it anywhere and run `WinPreview.exe`. Nothing needs to be installed; .NET and the Windows App SDK are included. To update from an earlier version, unzip into a new folder (unzipping over the old one would leave behind files this version no longer uses).

> The app isn't code-signed yet, so Windows SmartScreen may warn on first launch. Choose **More info → Run anyway**. The SHA-256 checksum is in `Win-Preview-v0.4-win-x64.zip.sha256`.

## New in v0.4

**Smaller package**
- The download is about half the size, and the unzipped folder is around 130 MB instead of 280 MB.
- Unused parts of .NET and the Windows SDK are now trimmed out when the app is built.
- Windows App SDK components the app never used (Windows ML with DirectML, Windows AI, Widgets) are no longer bundled.
- Only English runtime resources are included.
