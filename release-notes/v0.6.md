Win-Preview v0.6 lets text boxes use any font installed on your PC, and fixes several cases where text box and note text could disappear.

## Download

**Win-Preview-v0.6-win-x64.zip** is for Windows 10 (1809+) and Windows 11, x64. Unzip it anywhere and run `WinPreview.exe`. Nothing needs to be installed; .NET and the Windows App SDK are included. To update from an earlier version, unzip into a new folder (unzipping over the old one would leave behind files this version no longer uses).

> The app isn't code-signed yet, so Windows SmartScreen may warn on first launch. Choose **More info → Run anyway**. The SHA-256 checksum is in `Win-Preview-v0.6-win-x64.zip.sha256`.

## New in v0.6

**Any installed font for text boxes**
- The font list now has every font installed on your PC, not only Helvetica, Times and Courier.
- Each name is shown in its own font. Type in the search field at the top to find a font; Enter picks the first match.
- The font is embedded in the saved PDF, so the text looks the same on other computers. Installed fonts also work for languages that Helvetica, Times and Courier can't show.
- Each embedded font adds its file size to the PDF (about 1 MB for most fonts, more for Chinese, Japanese and Korean fonts). Helvetica, Times and Courier add nothing.
- Fonts whose license doesn't allow embedding, and PostScript-outline (CFF) `.otf` fonts, aren't listed.

## Fixed in v0.6

**Text boxes**
- After typing several lines, clicking off the box or resizing it could leave only the top line visible.
- Double-clicking a text box to edit it deleted every line but the first.
- Changing the font or size of a text box could hide its lower lines. The box now grows to fit.
- Editing a text box you had made narrower widened it back out to the edge of the page.
- Zooming while typing in a text box left the editor in the wrong place and could resize the box.
- Text boxes on rotated PDF pages were saved sideways (they looked right in Win-Preview but not in other PDF viewers).

**Notes**
- Opening a sticky note again deleted every line but the first.
